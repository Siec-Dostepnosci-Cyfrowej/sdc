Zbiór stanowi wzorzec, który podmiot publiczny może przyjąć lub dostosować do własnych kanałów, narzędzi i rodzajów publikowanych materiałów. Standardy przekładają wymagania dostępności na zasady codziennej pracy. Nie zastępują przepisów prawa, norm technicznych ani specjalistycznego badania dostępności.
