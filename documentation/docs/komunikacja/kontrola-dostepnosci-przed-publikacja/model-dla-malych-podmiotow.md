# Wariant uproszczony kontroli dla małych podmiotów

Wariant jest przeznaczony dla organizacji, w których publikacją zajmuje się jedna osoba lub niewielki zespół. Uproszczenie dotyczy organizacji i dokumentowania, a nie rezygnacji z kontroli dostępności.

## Organizacja

- jedna osoba może przygotować, sprawdzić i opublikować materiał,
- jeżeli jest to możliwe, materiały o wyższym ryzyku warto przekazać do dodatkowego sprawdzenia,
- podmiot określa, kto może podjąć decyzję o publikacji warunkowej,
- stosuje się krótkie listy kontrolne odpowiednie do rodzaju materiału.

## Minimalny przebieg

1. Określ typ materiału i kanał publikacji.
2. Sprawdź materiał odpowiednią krótką listą lub innym narzędziem.
3. Odnotuj wynik i decyzję w używanym już narzędziu, np. CMS, systemie zadań lub prostej karcie.
4. Opublikuj materiał albo skieruj go do poprawy, wstrzymaj publikację lub – w uzasadnionej sytuacji – zastosuj publikację warunkową.

## Kiedy zwiększyć zakres kontroli

Pełniejszą kontrolę należy rozważyć szczególnie wtedy, gdy materiał służy wykonaniu zadania lub procedury, dotyczy praw i obowiązków, zawiera formularz lub złożony dokument, trafia do dużej grupy odbiorców albo podobne materiały były wcześniej źródłem błędów lub zgłoszeń.
