# Wariant uproszczony procedury dla małych podmiotów

Wariant jest przeznaczony dla podmiotów, w których publikacją zajmuje się jedna osoba albo niewielki zespół. Uproszczenie dotyczy organizacji i dokumentowania, a nie rezygnacji z kontroli dostępności.

## Minimalny model

1. Osoba przygotowuje materiał i określa jego typ oraz kanał publikacji.
2. Ta sama lub druga osoba sprawdza materiał z użyciem odpowiedniej krótkiej listy kontrolnej albo innego przyjętego narzędzia.
3. Wynik i decyzja są odnotowywane w prosty sposób, np. w zadaniu, CMS, arkuszu lub krótkiej karcie kontroli.
4. Materiał jest publikowany, kierowany do poprawy, wstrzymywany albo — wyjątkowo — obejmowany publikacją warunkową.

Jedna osoba może pełnić wszystkie funkcje. W takim przypadku powinna wykonać je kolejno i odnotować wynik kontroli przed publikacją.

## Kiedy rozszerzyć kontrolę

Pełniejsza kontrola jest wskazana w szczególności dla treści związanych z prawami lub obowiązkami użytkowników, formularzy i komunikatów transakcyjnych, dokumentów używanych w procedurach administracyjnych, materiałów kierowanych do dużej grupy odbiorców oraz treści, które wcześniej były źródłem błędów lub zgłoszeń.
