# Lista kontrolna dokumentów PDF, DOCX i XLSX

Lista służy do wstępnej kontroli dokumentów udostępnianych jako pliki do pobrania lub załączniki. Nie zastępuje kontroli właściwej dla konkretnego formatu ani specjalistycznej oceny plików złożonych. W przypadku dokumentu złożonego lub wysokiego ryzyka wynik tej listy powinien prowadzić do dodatkowej kontroli odpowiedniej dla formatu i funkcji dokumentu.

| Punkt kontrolny | Zastosowanie | Skutek odpowiedzi „NIE” | Odpowiedź | Dowód/uwaga |
|---|---|---|---|---|
| Czy użytkownik może odczytać treść dokumentu w logicznej kolejności i rozpoznać jego strukturę? | zawsze, jeżeli punkt odpowiada rodzajowi materiału | wymaga poprawy albo udokumentowanej decyzji o dalszym postępowaniu | TAK / NIE / NIE DOTYCZY |  |
| Czy dokument ma określony właściwy język oraz tytuł pozwalający go zidentyfikować? | gdy wskazany element lub funkcja występuje | jeżeli punkt dotyczy materiału — wymaga poprawy albo udokumentowanej decyzji o dalszym postępowaniu | TAK / NIE / NIE DOTYCZY |  |
| Czy nagłówki, listy, tabele i inne elementy mają właściwą strukturę semantyczną, a nie tylko wygląd wizualny? | zawsze, jeżeli punkt odpowiada rodzajowi materiału | wymaga poprawy albo udokumentowanej decyzji o dalszym postępowaniu | TAK / NIE / NIE DOTYCZY |  |
| Czy osoba, która nie widzi obrazów lub wykresów, otrzymuje równoważną informację, jeżeli element jest informacyjny? | gdy wskazany element lub funkcja występuje | jeżeli punkt dotyczy materiału — wymaga poprawy albo udokumentowanej decyzji o dalszym postępowaniu | TAK / NIE / NIE DOTYCZY |  |
| Czy tabele danych mają możliwe do rozpoznania nagłówki i nie są używane wyłącznie do układu strony? | gdy wskazany element lub funkcja występuje | jeżeli punkt dotyczy materiału — wymaga poprawy albo udokumentowanej decyzji o dalszym postępowaniu | TAK / NIE / NIE DOTYCZY |  |
| Czy znaczenie informacji nie zależy wyłącznie od koloru, położenia lub formatowania? | zawsze, jeżeli punkt odpowiada rodzajowi materiału | wymaga poprawy albo udokumentowanej decyzji o dalszym postępowaniu | TAK / NIE / NIE DOTYCZY |  |
| Czy dokument będący skanem został przetworzony tak, aby tekst był możliwy do odczytu, a wynik OCR został zweryfikowany i uzupełniony o potrzebną strukturę? | gdy wskazany element lub funkcja występuje | jeżeli punkt dotyczy materiału — wymaga poprawy albo udokumentowanej decyzji o dalszym postępowaniu | TAK / NIE / NIE DOTYCZY |  |
| Czy linki pozwalają zrozumieć ich cel na podstawie nazwy lub bezpośredniego kontekstu? | gdy wskazany element lub funkcja występuje | jeżeli punkt dotyczy materiału — wymaga poprawy albo udokumentowanej decyzji o dalszym postępowaniu | TAK / NIE / NIE DOTYCZY |  |
| Czy elementy interaktywne, jeżeli występują, mają etykiety i można z nich korzystać bez myszy? | gdy wskazany element lub funkcja występuje | jeżeli punkt dotyczy materiału — wymaga poprawy albo udokumentowanej decyzji o dalszym postępowaniu | TAK / NIE / NIE DOTYCZY |  |
| Czy przy dokumencie złożonym lub wysokiego ryzyka wykonano dodatkową kontrolę właściwą dla jego formatu i funkcji, np. strukturę i kolejność odczytu PDF, strukturę dokumentu DOCX albo arkusze, tabele i wykresy XLSX? | zależnie od charakteru materiału | wymaga oceny wpływu na odbiór informacji lub wykonanie zadania | TAK / NIE / NIE DOTYCZY |  |

## Decyzja

- publikacja,
- skierowanie do poprawy,
- wstrzymanie publikacji,
- publikacja warunkowa w uzasadnionej sytuacji.
