# Lista kontrolna dokumentów PDF, DOCX i XLSX

Lista wspiera kontrolę dokumentów udostępnianych jako pliki do pobrania lub załączniki. Nie zastępuje pełnego badania dokumentu ani specjalistycznej oceny plików złożonych.

| Punkt kontrolny | Kategoria | Odpowiedź | Dowód/uwaga |
|---|---|---|---|
| Czy użytkownik może odczytać treść dokumentu w logicznej kolejności i rozpoznać jego strukturę? | krytyczne | TAK / NIE / NIE DOTYCZY | |
| Czy dokument ma określony właściwy język oraz tytuł pozwalający go zidentyfikować? | warunkowe | TAK / NIE / NIE DOTYCZY | |
| Czy nagłówki, listy, tabele i inne elementy mają właściwą strukturę semantyczną, a nie tylko wygląd wizualny? | krytyczne | TAK / NIE / NIE DOTYCZY | |
| Czy osoba, która nie widzi obrazów lub wykresów, otrzymuje równoważną informację, jeżeli element jest informacyjny? | warunkowe | TAK / NIE / NIE DOTYCZY | |
| Czy tabele danych mają możliwe do rozpoznania nagłówki i nie są używane wyłącznie do układu strony? | warunkowe | TAK / NIE / NIE DOTYCZY | |
| Czy znaczenie informacji nie zależy wyłącznie od koloru, położenia lub formatowania? | krytyczne | TAK / NIE / NIE DOTYCZY | |
| Czy dokument będący skanem został przetworzony tak, aby tekst był możliwy do odczytu, a wynik OCR został zweryfikowany i uzupełniony o potrzebną strukturę? | warunkowe | TAK / NIE / NIE DOTYCZY | |
| Czy linki pozwalają zrozumieć ich cel na podstawie nazwy lub bezpośredniego kontekstu? | warunkowe | TAK / NIE / NIE DOTYCZY | |
| Czy elementy interaktywne, jeżeli występują, mają etykiety i można z nich korzystać bez myszy? | warunkowe | TAK / NIE / NIE DOTYCZY | |
| Czy przy dokumencie złożonym lub wysokiego ryzyka wykonano dodatkową kontrolę odpowiednią do jego funkcji? | jakościowe | TAK / NIE / NIE DOTYCZY | |

## Decyzja

- publikacja,
- skierowanie do poprawy,
- wstrzymanie publikacji,
- publikacja warunkowa w uzasadnionej sytuacji.
