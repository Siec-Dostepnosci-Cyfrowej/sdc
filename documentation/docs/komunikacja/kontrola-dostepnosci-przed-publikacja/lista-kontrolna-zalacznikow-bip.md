# Lista kontrolna załączników publikowanych w BIP

| Punkt kontrolny | Zastosowanie | Skutek odpowiedzi „NIE” | Odpowiedź | Dowód/uwaga |
|---|---|---|---|---|
| Czy przed publikacją ustalono, czy załącznik podlega wymaganiom dostępności cyfrowej? | zawsze, jeżeli punkt odpowiada rodzajowi materiału | wymaga poprawy albo udokumentowanej decyzji o dalszym postępowaniu | TAK / NIE / NIE DOTYCZY |  |
| Czy treść załącznika jest dostępna w formie pozwalającej użytkownikowi odczytać informację i wykonać związane z nią zadanie? | zawsze, jeżeli punkt odpowiada rodzajowi materiału | wymaga poprawy albo udokumentowanej decyzji o dalszym postępowaniu | TAK / NIE / NIE DOTYCZY |  |
| Czy nazwa i opis linku do pliku pozwalają zrozumieć, czego dotyczy dokument i jaki ma format? | gdy wskazany element lub funkcja występuje | jeżeli punkt dotyczy materiału — wymaga poprawy albo udokumentowanej decyzji o dalszym postępowaniu | TAK / NIE / NIE DOTYCZY |  |
| Czy dokument ma strukturę, język i treści równoważne właściwe dla jego typu? | gdy wskazany element lub funkcja występuje | jeżeli punkt dotyczy materiału — wymaga poprawy albo udokumentowanej decyzji o dalszym postępowaniu | TAK / NIE / NIE DOTYCZY |  |
| Czy zeskanowany dokument został poddany OCR, wynik zweryfikowano, a dokument uzupełniono o potrzebną strukturę zamiast pozostawienia samego obrazu tekstu? | gdy wskazany element lub funkcja występuje | jeżeli punkt dotyczy materiału — wymaga poprawy albo udokumentowanej decyzji o dalszym postępowaniu | TAK / NIE / NIE DOTYCZY |  |
| Czy w przypadku powołania się na ustawowe wyłączenie, alternatywny sposób dostępu lub nadmierne koszty spełniono odpowiednie warunki wynikające z przepisów, niezależnie od wewnętrznej decyzji publikacyjnej? | gdy wskazany element lub funkcja występuje | jeżeli punkt dotyczy materiału — wymaga poprawy albo udokumentowanej decyzji o dalszym postępowaniu | TAK / NIE / NIE DOTYCZY |  |
| Czy użytkownik może łatwo ustalić znaczenie i aktualność załącznika? | zależnie od charakteru materiału | wymaga oceny wpływu na odbiór informacji lub wykonanie zadania | TAK / NIE / NIE DOTYCZY |  |

## Decyzja

- publikacja,
- skierowanie do poprawy,
- wstrzymanie publikacji,
- publikacja warunkowa w uzasadnionej sytuacji.
