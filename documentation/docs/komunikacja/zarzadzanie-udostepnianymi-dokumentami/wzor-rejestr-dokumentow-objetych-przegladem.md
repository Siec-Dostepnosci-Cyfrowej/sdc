## Cel rejestru

Rejestr dokumentów objętych przeglądem służy do:

- prowadzenia ewidencji dokumentów objętych procesem;
- dokumentowania wyników oceny dokumentów;
- monitorowania działań dotyczących dokumentów;
- zarządzania terminami realizacji działań;
- zapewnienia możliwości odtworzenia przebiegu procesu.

Rejestr stanowi podstawowe narzędzie organizacyjne wspierające zarządzanie publicznie udostępnianymi dokumentami urzędowymi.

---

## Charakter rejestru

Rejestr powinien mieć postać:

- arkusza kalkulacyjnego;
- systemu informatycznego;
- bazy danych;
- innego rozwiązania umożliwiającego uporządkowane prowadzenie danych.

Rejestr powinien umożliwiać:

- filtrowanie danych;
- sortowanie danych;
- wyszukiwanie dokumentów;
- aktualizowanie statusów;
- przygotowywanie zestawień i raportów.

Każdy dokument powinien posiadać odrębny wpis w rejestrze.

W przypadku dokumentów o identycznym charakterze dopuszczalne jest prowadzenie wpisów zbiorczych, jeżeli nie utrudnia to podejmowania decyzji i monitorowania działań.

---

## Zakres danych rejestru

### 1. Identyfikacja dokumentu

Rejestr powinien zawierać co najmniej:

| Pole | Opis |
|---|---|
| Identyfikator dokumentu | unikalny identyfikator wpisu |
| Nazwa dokumentu | nazwa albo krótki opis dokumentu |
| Link albo lokalizacja | adres URL albo miejsce publikacji |
| Format dokumentu | np. PDF, DOCX, XLSX, skan |
| Data publikacji | data pierwszego opublikowania |
| Data aktualizacji | data ostatniej aktualizacji, jeżeli występuje |

---

### 2. Informacje organizacyjne

| Pole | Opis |
|---|---|
| Komórka organizacyjna odpowiedzialna | jednostka odpowiedzialna za dokument |
| Osoba odpowiedzialna | osoba prowadząca sprawę albo dokument |
| Obszar tematyczny | opcjonalna klasyfikacja dokumentu |

---

### 3. Wyniki oceny dokumentu

| Pole | Opis |
|---|---|
| Wynik oceny „niezbędności” | dokument niezbędny / ograniczony / archiwalny / zbędny |
| Znaczenie dla użytkowników | wysoki / średni / niski |
| Aktualność dokumentu | aktualny / częściowo aktualny / nieaktualny |
| Możliwość edycji | tak / nie |
| Stan dostępności | wymaga działań / częściowo dostępny / dostępny |

---

### 4. Decyzja dotycząca dokumentu

| Pole | Opis |
|---|---|
| Sposób dalszego postępowania | dostosowanie / odtworzenie / nowa wersja / archiwizacja / usunięcie |
| Priorytet realizacji | 1 / 2 / 3 / 4 / 0A / 0 |
| Termin realizacji | planowany termin wykonania działań |
| Status realizacji | nie rozpoczęto / w trakcie / zakończono / wstrzymano |

---

### 5. Informacje o realizacji działań

| Pole | Opis |
|---|---|
| Data wykonania | data zakończenia działań |
| Forma wykonanego działania | opis wykonanych działań |
| Wynik weryfikacji | pozytywny / wymaga poprawek |
| Osoba weryfikująca | osoba wykonująca kontrolę |
| Data zatwierdzenia | data zatwierdzenia działań |

---

### 6. Uwagi dodatkowe

Rejestr powinien umożliwiać odnotowywanie informacji dodatkowych, w szczególności dotyczących:

- ograniczeń prawnych;
- problemów technicznych;
- obowiązków archiwalnych;
- potrzeby dodatkowych działań;
- szczególnych decyzji organizacyjnych.

---

## Zasady prowadzenia rejestru

### Zasada kompletności

Rejestr powinien obejmować wszystkie dokumenty objęte przeglądem.

Dokument nie powinien pozostawać poza rejestrem, jeżeli został objęty procesem oceny albo działań organizacyjnych.

---

### Zasada aktualności

Dane w rejestrze powinny być aktualizowane na bieżąco.

Zmiana statusu dokumentu albo wykonanie działania powinny być niezwłocznie odnotowywane.

---

### Zasada jednoznaczności danych

Dla pól kluczowych należy stosować jednolite wartości i słowniki pojęć.

W szczególności dotyczy to:

- statusów realizacji;
- priorytetów;
- wyników oceny;
- sposobów postępowania z dokumentami.

---

### Zasada odtwarzalności

Rejestr powinien umożliwiać ustalenie:

- kto dokonał oceny;
- kto podjął decyzję;
- kto realizował działania;
- kto przeprowadził weryfikację;
- kiedy wykonano poszczególne czynności.

---

### Zasada użyteczności organizacyjnej

Rejestr powinien wspierać:

- planowanie działań;
- monitorowanie postępów;
- identyfikację opóźnień;
- przygotowywanie raportów;
- kontrolę realizacji procesu.

---

## Zalecane rozwiązania organizacyjne

W celu zwiększenia czytelności i użyteczności rejestru zaleca się:

- stosowanie list rozwijanych;
- stosowanie filtrów;
- stosowanie formatowania warunkowego;
- wyróżnianie dokumentów wymagających pilnych działań;
- zabezpieczenie pól kluczowych przed przypadkową zmianą.

---

## Raportowanie i wykorzystanie danych

Dane z rejestru powinny umożliwiać przygotowywanie zestawień dotyczących:

- liczby dokumentów;
- postępu realizacji działań;
- dokumentów wymagających pilnych działań;
- dokumentów archiwalnych;
- dokumentów przeznaczonych do usunięcia;
- najczęściej występujących problemów.

---

## Powiązanie rejestru z innymi dokumentami

Rejestr powinien pozostawać powiązany z:

- formularzami oceny dokumentów;
- harmonogramami działań;
- raportami;
- dokumentacją dotyczącą decyzji i weryfikacji.

---

## Efekt stosowania rejestru

Prowadzenie rejestru umożliwia:

- uporządkowane zarządzanie dokumentami;
- monitorowanie realizacji działań;
- ograniczenie chaosu informacyjnego;
- zapewnienie spójności procesu;
- wykazanie realizacji działań organizacyjnych dotyczących dostępności cyfrowej dokumentów.

Rejestr wspiera trwałe zarządzanie publicznie udostępnianymi dokumentami urzędowymi, a nie wyłącznie jednorazowy przegląd zasobu.
