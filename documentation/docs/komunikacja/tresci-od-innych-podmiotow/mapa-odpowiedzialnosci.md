Nazwy stanowisk można dostosować do struktury podmiotu. Każde zadanie powinno mieć wskazanego wykonawcę i właściciela rozstrzygnięcia.

| Etap | Odpowiedzialny | Wsparcie |
|---|---|---|
| Przekazanie kompletnego materiału | podmiot przekazujący | właściciel merytoryczny |
| Ustalenie celu i obowiązku publikacji | właściciel merytoryczny | obsługa prawna |
| Kontrola kompletności | redaktor | podmiot przekazujący |
| Kontrola dostępności | redaktor lub wskazany specjalista | koordynator dostępności |
| Ocena uprawnienia do modyfikacji i wyłączenia | właściciel merytoryczny | koordynator dostępności, obsługa prawna |
| Dostosowanie materiału | podmiot przekazujący albo uprawniony pracownik | specjalista ds. dostępności |
| Publikacja i dokumentowanie | redaktor | właściciel merytoryczny |
| Obsługa żądania dostępności | wyznaczony punkt kontaktu | redaktor, koordynator dostępności, właściciel merytoryczny |
| Nadzór i doskonalenie procesu | kierownictwo | koordynator dostępności |

## Mały podmiot

Jedna osoba może wykonywać kilka ról, ale powinna przejść wszystkie etapy oceny. Przypadki dotyczące podstawy prawnej wyłączenia lub konfliktu obowiązków kieruje do konsultacji.

## Duży podmiot

Warto ustanowić centralne wymagania dla materiałów, jeden formularz przekazania, rejestr rozstrzygnięć oraz wskazane punkty konsultacji. Odpowiedzialność za treść pozostaje po stronie właściciela merytorycznego, a odpowiedzialność za techniczne wykonanie publikacji — po stronie redaktora lub administratora.
