Lista służy do wstępnej kontroli materiału. Nie jest pełnym badaniem zgodności i nie potwierdza samodzielnie spełnienia wszystkich wymagań dostępności cyfrowej.

Odpowiedzi udzielaj w formie: **tak**, **nie** albo **nie dotyczy**. Odpowiedź „nie” wymaga opisania problemu i ustalenia dalszego działania. Zakres pełnej weryfikacji dobierz do rodzaju materiału.

## Kompletność i odpowiedzialność

- [ ] Wskazano podmiot przekazujący i właściciela merytorycznego.
- [ ] Materiał jest kompletny i zawiera wszystkie załączniki.
- [ ] Ustalono podstawę i miejsce publikacji.
- [ ] Przekazano plik edytowalny lub wyjaśniono, dlaczego go nie ma.
- [ ] Ustalono uprawnienie podmiotu publikującego do modyfikacji.

## Dokumenty i strony

- [ ] Tytuł dokumentu lub strony opisuje treść.
- [ ] Oznaczono język dokumentu i zmianę języka fragmentów.
- [ ] Nagłówki, listy i tabele mają prawidłową strukturę.
- [ ] Kolejność odczytu jest logiczna.
- [ ] Grafiki informacyjne mają odpowiedniki tekstowe, a dekoracyjne są pomijane przez technologie wspomagające.
- [ ] Linki opisują cel i nie opierają się wyłącznie na adresie URL.
- [ ] Kontrast tekstu i elementów graficznych jest wystarczający.
- [ ] Informacja nie jest przekazywana wyłącznie kolorem.
- [ ] Treść pozostaje czytelna po powiększeniu i zmianie orientacji, jeżeli dotyczy.
- [ ] Dokument nie jest skanem bez rozpoznanej i sprawdzonej warstwy tekstowej.

## Multimedia

- [ ] Nagranie ma wymagane napisy.
- [ ] Nagranie ma transkrypcję lub audiodeskrypcję, jeżeli jest wymagana.
- [ ] Odtwarzacz można obsłużyć klawiaturą.
- [ ] Automatyczne odtwarzanie, miganie i ruch nie tworzą barier.

## Formularze i elementy interaktywne

- [ ] Wszystkie funkcje można obsłużyć klawiaturą.
- [ ] Pola formularzy mają etykiety i zrozumiałe instrukcje.
- [ ] Komunikaty o błędach wskazują problem i sposób jego poprawy.
- [ ] Fokus klawiatury jest widoczny i porusza się w logicznej kolejności.

## Weryfikacja końcowa

- [ ] Materiał sprawdzono narzędziami i technologią wspomagającą odpowiednimi do jego rodzaju.
- [ ] Stwierdzone problemy opisano i przypisano osobę odpowiedzialną za dalsze działanie.
- [ ] Zapisano wynik oceny oraz podstawę sposobu postępowania.
